# MilitarySkins

MoonLoader-скрипт для SA-MP: показывает выбранным игрокам отдельные облики
(СВ, ОСН, ФБР, Президент) у всех, у кого установлен скрипт. Назначения общие
и приходят из облачного списка. Автор S.Kazama.

Инструкция для игроков: [README_RU.md](README_RU.md).

## Установка

**Скачать: https://github.com/JJKenn3dy/MilitarySkins/releases/latest/download/MilitarySkins.zip**
(ссылка всегда ведёт на последнюю версию).

Полностью закрыть GTA, распаковать архив в папку игры (где gta_sa.exe) с заменой файлов
и запустить `Install_MilitarySkins.cmd`. Ставится один раз, дальше скрипт обновляется сам.
Откат: `Rollback_MilitarySkins.cmd` при закрытой игре.

## Структура

- `MilitarySkins_Package/payload/MoonLoader` — сам скрипт, модули и модели DFF/TXD.
- `MilitarySkins_Package/manifest.json` — SHA256 каждого файла, по нему проверяет установщик.
- `MilitarySkins_Package/install.ps1` — установка с резервом и откат.
- `tools/` — служебные скрипты для разработки.

## Обновления у игроков

Начиная с 4.4.4 скрипт (`release_updater.lua`) сам берёт `manifest.json` из последнего релиза
(`releases/latest`), скачивает изменившиеся файлы по тегу `v<версия>`, сверяет SHA256
и перезагружается без перезапуска игры. Ставится только версия новее установленной.
Поэтому всё, что попало в релиз, через полчаса окажется у всех игроков с автообновлением.
Релиз публиковать только после проверки в игре.

## Как вносить изменения

1. Изменить файлы в `payload`.
2. При выпуске новой версии поменять `local VERSION` в `MilitarySkins.lua`
   и заголовок `README_RU.md` (install.ps1 берёт версию из manifest.json).
3. `python tools/update_manifest.py --version 4.3.2`: пересчитать хеши и версию,
   иначе установщик откажется ставить.
4. Закоммитить и отправить, проверить в игре.
5. `python tools/publish_release.py --dry-run`, затем без `--dry-run`: релиз с
   `manifest.json` и архивом. Архив отдельно собирает `python tools/build_release.py`.

Окончания строк в репозитории не преобразуются (`.gitattributes`): иначе хеши разойдутся.
Личные файлы игрока (`cloud_credentials.json`, журналы) в репозиторий не добавлять.
