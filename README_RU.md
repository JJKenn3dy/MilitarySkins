# MilitarySkins 4.3.1

Панель: https://military-skins-api.lightlygamer091.workers.dev

Мод меняет облик выбранных персонажей у пользователей MilitarySkins. Игроки без скрипта и моделей видят серверные скины. Для общего генерала и исправления анимаций всем участникам нужно обновиться до 4.3.0.

## Установка

При закрытой GTA распаковать архив в корень игры и запустить `Install_MilitarySkins.cmd`. Для отката при закрытой игре — `Rollback_MilitarySkins.cmd`. Установщик проверяет файлы, сохраняет резервную копию и персональные настройки; отключает отдельные Soldier179.lua/ShunSkin61.lua, если они есть.

Нужны GTA SA 1.0 US, SA-MP 0.3.7-R3, MoonLoader 0.26, SAMPFUNCS, SAMP.Lua (`samp.events`), `encoding`. Сторонние загрузчики не входят в архив. Пакет содержит 17 моделей, включая генеральскую, ОСН и FBI. Паролей, личных ключей, журналов и пользовательских назначений в архиве нет.

После обновления полностью закрыть и заново запустить GTA. Перезагрузка одного скрипта не восстановит анимации, которые уже сбросила старая версия.

## Обновления и перезагрузка

С версии 4.3.1 скрипт сам проверяет новые версии: через 30 секунд после появления
персонажа и затем раз в 30 минут. Новая версия скачивается, каждый файл сверяется по
SHA256, после этого файлы заменяются и скрипт перезагружается без перезапуска игры.
Ставится только версия новее установленной. Личные настройки облака не меняются.

- `/mskin update` — проверить сейчас.
- `/mskin update status` — версия и результат последней проверки.
- `/mskin update off` / `on` — выключить или включить автообновление.
- `/mskin update rollback` — вернуть файлы, заменённые последним обновлением; автообновление при этом выключается.
- `/mskin reload` — перезагрузить скрипт без перезапуска игры.

Те же пункты есть в меню `/mskin`. Если обновление затронуло сетевую библиотеку
`cloud_http.dll`, она заработает после перезапуска игры, остальное сразу.

## Меню и категории

`/mskin` → «Назначить облик игроку» → ID из TAB или ник → категория → облик. При вводе ID сохраняется ник.

- **Сухопутные войска**: генерал, полковник, капитан, полевые и армейские бойцы, серия ОСН SFU-17.
- **ФБР**: оперативник 120 и разведчик FBI.
- **Правительство**: президент Республики на основе ID 147, код назначения **147**.

Генерал теперь доступен в общем списке под кодом **1061**, отдельно от офицера 61. `/mskin general on` назначает его своему нику у всех пользователей; `/mskin general off` снимает именно это назначение. Требуются права управляющего. Геометрия и текстуры генерала не изменены. Старые клиенты получают совместимый список без общего генерала и должны обновиться, чтобы его видеть.

## Свой облик

- «Скрыть мой назначенный облик», `/mskin me off`: скрыть замену только на своём экране. Остальные её видят. `/mskin me on` возвращает показ.
- **«Сбросить мой скин у всех»**, `/mskin me reset`: удалить общее назначение своего ника. Все пользователи увидят обычный серверный скин после обновления списка, обычно за пять секунд. Управляющий позднее может назначить новый облик.
- «Выбрать облик себе»: доступно управляющему.

Для сброса у всех обычному игроку не нужны права на чужие назначения, но нужно один раз подтвердить свой ник. При первом сбросе создаётся запрос с коротким кодом. Владелец сверяет код с настоящим игроком во вкладке «Доступ» и нажимает **«Подтвердить ник»**. Затем игрок повторно нажимает кнопку сброса. Сервер определяет ник по разрешению; произвольный чужой ник в запросе сброса не принимается.

Cloudflare не может самостоятельно подтвердить владение аккаунтом SA-MP. Проверка кода нужна, чтобы посторонний не мог сбросить чужой скин по имени. Разрешение хранится на компьютере игрока, сервер хранит только его отпечаток. На новом компьютере потребуется новое подтверждение.

## Управляющие

«Получить доступ» → «Отправить» → сообщить короткий код владельцу. Владелец сверяет ник и код, нажимает **«Разрешить назначения»**. Доступ подключается автоматически. Код действует 10 минут. Действующие разрешения сохранены; роли «только свой скин» и «управляющий» показаны отдельно. Отзыв разрешения запрещает и собственный сброс.

Зрителю для просмотра подтверждение не нужно. Пароль владельца и приватные файлы нельзя включать в раздаваемый архив.

## Анимации

В 4.2 заменяется геометрия существующего персонажа. Его clump, atomic, кадры скелета, HAnim и анимационные связи сохраняются. На живом персонаже больше не вызываются CPed::DeleteRwObject и CPed::SetModelIndex; нет пакетов смены скина или принудительного назначения анимаций.

Перед заменой проверяются структура, число и порядок костей, принадлежность персонажа нику и серверу. Исходная геометрия удерживается отдельной ссылкой; при снятии возвращается, при выходе из прорисовки освобождается. Неизменившийся скин не применяется повторно. Замена разрешена живым водителям и пассажирам без удаления персонажа.

Ранний перехват RPC отключён. Защита запуска, исправившая вылет 4.0, сохранена. HTTPS и назначения начинают работу через две секунды после собственного появления. Остаётся задержка сети, создания персонажа и загрузки модели: гарантировать назначение до его появления нельзя.

## Смена и маска

По журналам Exsellent: RGB `FFFFFF` — гражданский, `7A7667` — маска, `704214` — СВ. Гражданский цвет временно снимает замену, сохраняя облачное назначение. Маска сохраняет предыдущее состояние смены. Если клиент впервые видит уже замаскированного игрока, он ждёт подтверждения состояния смены.

Список перечитывается примерно каждые пять секунд. После 60 секунд без успешного ответа облачные назначения временно перестают применяться. `/mskin debug` — диагностика; `/mskin diag on/off` — временная запись событий.

## Президент 147

Добавлен согласованный деловой вариант: тёмный костюм, фиолетовый галстук, малый герб Республики, объёмные пуговицы, зажим, платок и часы. Лицо, тело и 32 кости исходного 147 сохранены. Президент доступен через меню и облачную панель. Обновление не меняет ранее назначенные облики; собственного генерала можно оставить выбранным.

Старые клиенты получают совместимый список без президента. Чтобы видеть этот облик, нужно установить полный пакет 4.3.0. Новая модель проверена в редакторе и повторно открыта из DFF/TXD; непосредственная проверка в GTA предстоит.

## Проверка

- 32-битный LuaJIT: память персонажа и скелета, одинаковые atomic/clump, переключение, восстановление, выход из прорисовки, чужая геометрия и несовместимые кости.
- Изолированный клиент: категории, ID, общий генерал себе и другому игроку, скрытие, сброс у всех, подтверждение ника, роли, смена/маска и защита запуска.
- Node/SQLite: права, отзыв, серверные границы, собственный сброс без возможности выбрать чужой ник, общий генерал и совместимый список старых клиентов.
- Непосредственно в GTA поворот головы, бег у второго игрока и посадка моделей после нового метода ещё требуют проверки. Автоматические проверки не заменяют её.
